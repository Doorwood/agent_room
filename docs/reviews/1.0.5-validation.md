# 1.0.5：聊天历史、附件和 Room 管理

1.0.5 包含项目名称同步、聊天历史、附件、Room 删除、模型中断和链接跳转。

- 聊天窗口首次显示最近 50 条记录，向上滚动或点击“加载更早的消息”继续加载。翻页时保持阅读位置，按事件序号去重，新消息不会覆盖已经加载的历史。单页同时限制文本体积。
- 历史仍以 host 的持久化事件为准。首次连接会同步 host 的记录，本机使用私有临时 SQLite 缓存保存完整聊天投影；内存仅保留有限尾部，窗口进程关闭后清理缓存。这里的懒加载指浏览器按页读取，不改变首次网络回放协议。
- 支持选择文件、粘贴图片及拖拽文件。文件通过固定证书的 TLS 和已有成员审批身份传到 host，上传完成后点击发送，文件名称和 host 路径随消息提交给模型。图片在发送前可预览，模型可通过图片查看工具读取上传路径。
- 单文件最多 20 MiB，每条消息最多 10 个附件，每个 room 的上传目录最多 1 GiB。上传按内容校验，重复上传复用相同文件路径。附件存放于 host state 的 `private/uploads`，不会自动执行；从草稿移除附件不删除已经上传的 host 文件。
- 上传需要 host 和客户端均升级。旧 host 继续支持文本聊天；尝试附件上传会提示升级。
- Dashboard 的“删除 Room”会断开该 Dashboard 的连接，并持久化移除列表记录。保留成员凭证、host 项目和聊天记录；不会撤销审批或停止其他终端。通过地址、session 和原昵称重新添加时复用已批准身份。

验证：全量 Go 测试和 go vet 通过；相关包 race 测试通过。历史分页测试覆盖 260 条记录、去重、超过内存尾部的状态更新和房间隔离；上传测试覆盖批准/未批准/撤销身份、实际文件字节、大小限制、内容校验失败、重试以及浏览器同源约束；删除测试覆盖断连、重启、重新添加与凭证保留。

3 项 Chromium 测试通过，覆盖原聊天和 Dashboard 流程、向上加载历史、文件与图片上传后发送，以及删除后的刷新。浏览器使用测试后端，网络层另有真实 TLS 传输测试；尚未进行 macOS/Safari/真实模型读取附件的实机验证。

## 停止当前模型任务

聊天输入区新增“停止模型”。通过现有 cancel 协议中断当前 turn，保持聊天连接；排队任务会继续执行。按钮只在已连接且有运行任务时可用。请求绑定界面上看到的 turn ID，并保留稳定请求 ID 供超时重试，防止误停下一项任务。host 接收请求后显示等待停止，最终状态以共享任务事件为准。复用现有 host 中断能力，不增加新的网络协议字段。

新增验证覆盖浏览器 cancel 请求的同源校验、断线/过期任务拒绝、host 确认、请求重试 ID 和快照中的活动任务；浏览器回归覆盖停止后连接保留及任务显示为已中断。

回复中的 Markdown 链接、普通网址和反引号包住的完整 HTTP(S) 网址均支持新标签页打开，保留原聊天页面。浏览器测试实际点击三种链接，校验目标页面及 opener 隔离；代码块保持代码格式。
