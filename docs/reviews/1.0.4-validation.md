## 本地体验

```sh
./dist/agent_room-linux-amd64 dashboard
```

或安装本次本地包：

```sh
npm install -g ./dist/npm/menmu-agent-room-1.0.4.tgz
agent_room dashboard
```

Dashboard 的断开只关闭本 Dashboard 的连接，不停止 host、不取消任务、不撤销凭证、不控制其他终端连接。
