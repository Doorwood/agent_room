# 受邀 Agent 使用 Host 项目隔离副本

版本：1.0.13；不包含在 npm 1.0.12 中。

## 使用方式

Dashboard 邀请 Agent 时默认选择“Host 项目 · 任务独立副本”，无需本机项目路径。Agent CLI 仍在邀请者本机运行，登录与原有权限检查保留；它处理的是 Host 项目的快照，不是同时挂载的 Host 主目录。旧的本机项目模式作为显式选项保留。

流程：Host 读取 Git 工作区 → 加入已完成直接依赖的文件变更 → 发送独立快照 → Dashboard 新建私有任务目录 → 本机 CLI 执行 → 回传文件差异 → Host 校验并生成新的私有结果目录 → 聊天返回目录与回执路径。

## 隔离与交接

- 每个任务都创建新的普通目录，不使用共享可写目录、硬链接或指向源文件的符号链接。
- Host 主目录永不在该通道内写入。其他 Agent 或人类对主目录的修改不会被回传覆盖。
- 结果目录保存在 Host workgroup/workspaces 下，旁边保存任务、成员、基线、增删改内容的 JSON 回执。每个成功结果对应不同目录；失败和未知回执不自动重试。
- 后续依赖任务基于当前 Host 快照组合上游净变更。变更前文件内容和执行位必须匹配基线；同路径的不同修改、删除与修改冲突会停止，无“最后写入者覆盖”。相同变更可去重，不同文件可组合。
- 同一条依赖链的中间结果携带累计变更，后续只依赖最近步骤也能获取此前修改。复杂多上游直接依赖若涉及不同版本的同一文件，会保守报告冲突。
- Host Codex 等原生成员仍使用原工作目录；它们通过结果中的 Host 副本路径读取受邀成员产物。该变更没有将所有 Host 模型执行转成独立工作区。
- 工作副本仅隔离项目文件，不是系统级沙箱。原生 CLI 保留其本机权限机制，不能把它描述为恶意命令隔离容器。

## 文件范围与传输

仅 Git 跟踪文件与未被 Git 忽略的新文件，包括未提交内容。跳过 Git 元数据、node_modules、__pycache__、.agent_room、.ssh、.aws、.npmrc、.env 及 .env.*。文件名称过滤不是通用密钥识别器；其他名称的文件会按项目内容传输。符号链接、硬链接与非普通文件拒绝处理，路径须相对于项目且不得越界。通过 os.Root 限制读取范围，并校验读取时文件身份与修改状态。

每个快照最多 10000 文件 / 32 MiB，单个传输帧最多 48 MiB。超过限制明确失败，不静默省略大型普通文件。Git 子模块、链接文件、大型项目和环境依赖自动安装暂不支持。文件的内容、增删与执行位可回传；其他权限、ACL、所有权不复制。

数据沿已有固定证书 TLS 与成员凭证通道传输。邀请、领取、完成均检查真实成员及 worker 所有者；只允许 work 权限的 Host 副本成员返回文件差异。只读成员返回修改会被拒绝。本机副本临时目录保留在用户缓存目录 agent_room/workspaces，便于未知回执后核对；暂不自动清理。

## 主项目合并

本次不自动合并结果至 Host 主目录，也不创建 Git 提交或推送。人类先验收结果目录和回执，再明确安排合并。需要主目录自动合并时，应另加基线校验、合并预览及冲突处理通道，不能直接覆盖文件。

## 验证

单元测试：越界路径、链接、排除项、独立副本、内容基线冲突、删除冲突、不同文件组合、跨步骤文件交接、Host 主目录不变。

集成测试：Dashboard 使用空本机项目路径邀请 Host 模式成员，通过真实本地 TLS 通道发送 Host 文件，使用模拟 Cursor CLI 产生修改，回传至 Host 独立目录，并验证主项目未改变。另保留旧本机模式回归。模拟 CLI 验证协议与文件流程，不代表真实 Cursor/Claude 云服务验收。
