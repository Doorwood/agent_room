# Host 只读入口与安装引导

版本：1.0.8。目的：Host 启动后可把一个浏览器 URL 分享给同网络协作者，对方无需先安装客户端就能了解如何加入。

## 使用流程

```sh
agent_room host .
```

新增输出示例：

```text
Host dashboard (read-only): http://192.168.1.10:7444/
```

该页面展示当前项目名称、Host 版本、连接地址和完整 session ID，以及：

1. 「检测本机 Dashboard」：主动打开本机检测页，显示正在运行的客户端版本。
2. 安装方法：Node.js 20+ 前置要求，持久化安装和全局 npm 安装命令；可直接复制。
3. 启动方法：`agent_room --version`、`agent_room dashboard`。
4. 「申请连接」：填写昵称，打开本机确认窗口核对 Host 和 Session 后提交。网页显示等待审批、已连接或失败状态；批准后在本机 Dashboard 打开对话。也可手动填写连接信息或复制终端加入命令。

Host 默认沿用协作服务的监听网卡，尝试 7444 端口；占用时分配可用端口，以启动输出为准。每次启动应查看实际 URL。固定入口可指定：

```sh
agent_room host . --web-listen 0.0.0.0:8080
```

使用者的网络需要能访问网页端口和协作端口。这是同网络的 HTTP 欢迎页，不将本机管理 Dashboard 改为网络监听。

## 只读范围

公共服务与管理 Dashboard 分开实现，不依赖项目数据库或模型执行接口。仅允许 GET / HEAD，路由为首页、静态资源和 `/info`；所有 POST、PUT、PATCH、DELETE 均拒绝。不给出聊天、问答、成员列表、项目绝对路径或本地 Dashboard 管理 URL。连接、删除、审批、上传、提交工作等操作不在公共服务中注册。

页面公开的 session ID 仅用于申请加入，不是已批准成员的凭据。正式访问仍走既有 TLS 连接和 Host 审批。页面随 Host 进程退出而关闭；关闭它不会操作 Room。

## 本机检测的准确含义

浏览器不能扫描用户电脑上的安装软件。实现检测的是「本机正在运行的新版本 Dashboard」，不把没有响应说成「未安装」。

新版 Dashboard 启动时尝试在 `127.0.0.1:18743` 提供一个检测与申请确认服务。端口占用不影响 Dashboard 本身；多个 Dashboard 进程下，检测到的是占用该检测端口的进程。该进程退出后，需要重新启动 Dashboard 才能重新占用检测端口。

- 用户点击按钮才打开本机检测页；不扫描端口，不自动执行安装或加入操作。
- 使用浏览器弹窗与 `postMessage` 回传版本，避免从 LAN 的 HTTP 页面直接跨域读取 localhost。
- 校验回传页面的 origin、窗口引用和一次性 nonce；检测只回传应用标识、版本、nonce；申请额外回传本次连接的状态枚举，不传错误详情。
- 本地管理 URL 仅在本机检测页里提供，用户自己点击打开；不回传给 Host 欢迎页。
- 检测服务只监听 loopback，校验 Host / Origin，不开放跨域读取。仅本机确认页可以用同源 JSON POST 调用 /join 与 /join-status；写请求必须带精确匹配的 Origin，限制正文大小并拒绝未知字段。
- 无响应、旧客户端、未启动或浏览器限制：统一显示无法确认，并给出终端版本检查与启动 / 更新方法。
- HTTP LAN 页面无法使用剪贴板 API 时，复制按钮选中文本并提示手动复制。

Host 和客户端需升级并重启后使用这套流程。旧版客户端仍可按页面上的普通加入命令连接，但不支持新的本机探测服务。


## 从欢迎页申请连接

公共 Host 页面仍无管理或写接口。「申请连接」通过弹窗 fragment 把公开的 Host 地址、Session 和昵称交给本机服务，由用户在本机窗口明确确认后提交。仅打开页面或检测不会创建身份或申请。

本机沿用 Dashboard 的凭据存储、TLS 校验和等待审批连接流程。相同地址、Session、昵称复用已有身份与活动连接，避免网页审批后重新申请。审批角色仍由 Host 决定；本机管理 URL 和身份 token 均不回传到公共网页。

需要在访问者电脑安装并运行支持此功能的 Dashboard。未安装、未启动、旧版本或弹窗被拦截时，不能确认申请状态，页面引导安装 / 更新 / 启动；不能据此声称申请被取消。关闭确认窗口只停止页面状态反馈，已经提交的申请与本机连接继续存在，可从本机 Dashboard 管理。刷新欢迎页后可用相同昵称再次确认来恢复状态。

此流程不支持仅凭未安装客户端的浏览器完成申请。公共页面只提供申请入口，实际申请凭据始终保存在用户本机，并通过既有受信任 TLS 通道提交。
