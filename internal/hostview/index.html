2. 尚未安装？一条命令准备好
适用于 macOS / Linux，需要 Node.js 20+。在自己的终端执行，安装后可在新终端继续使用。
如果提示找不到 npm，请先安装 Node.js，再运行安装命令。
npm exec --yes --registry=https://registry.npmjs.org/ --package=menmu-agent-room@latest -- agent_room-setup
export PATH="$HOME/.local/bin:$PATH"
agent_room dashboard
使用全局 npm 安装 / 更新
npm install -g menmu-agent-room@latest --registry=https://registry.npmjs.org/
agent_room dashboard
持久化安装用户使用 agent_room-update 更新。更新后重启本地 Dashboard。
本项目目前支持 macOS / Linux，不提供 Windows 原生客户端。
